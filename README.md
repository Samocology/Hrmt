# HRMT - Human Resource Management Tool

A modern Human Resource Management application built with React, TypeScript, and Vite.

## 🚀 Tech Stack

- **Frontend:** React 19
- **Language:** TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Routing:** TanStack Router
- **Package Manager:** npm

## 📋 Prerequisites

- Node.js (v18 or higher)
- npm (v9 or higher)
